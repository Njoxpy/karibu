The **Admin Page** is a crucial component of the Savarrah project, designed to provide the administrator with comprehensive oversight and control over the various businesses under the Savarrah brand. Here's a detailed explanation of the different sections and functionalities of the Admin Page:

### 1. **Header**

- **Logo**: Displays the Savarrah logo, serving as a home link to redirect to the dashboard.
- **Navigation Menu**: Provides links to different sections of the admin panel, such as:
  - Overview
  - Savarrah Printing
  - Savarrah Animal Feeding
  - Savarrah Fresh Oil
  - Savarrah Godown
  - Savarrah Stationery
  - Savarrah Hardware
  - Orders
  - Reports
  - Settings
- **Logout Button**: Allows the admin to securely log out of the account.

### 2. **Dashboard Overview Section**

- **Key Metrics**: Displays important statistics that provide a snapshot of the overall performance of all companies.
  - **Total Sales**: Cumulative sales for each company, enabling quick assessment of financial health.
  - **Number of Orders**: Indicates how many orders have been placed on a particular day.
  - **Total Inventory**: Overview of available stock across all companies, helping with inventory management.
  - **Recent Activities**: A feed that shows the latest changes or actions taken within the admin panel, such as new orders, updates to products, etc.
- **Graphs and Charts**: Visual representations of data trends, such as sales over time, which can help identify patterns and make informed decisions.

### 3. **Company Management**

- **List of Companies**: Displays all companies under the Savarrah brand in a table format, including:
  - **Company Name**: The name of each business (e.g., Savarrah Printing, Savarrah Animal Feeding).
  - **Total Sales**: Current sales figures for each company.
  - **Active Products**: The number of products currently available for sale.
  - **Action Buttons**: Options to edit or delete company information.
    - **Edit**: Redirects to a form where the admin can update company details such as name, description, and contact information.
    - **Delete**: Allows the admin to remove the company from the system, with a confirmation prompt to prevent accidental deletions.

### 4. **Order Management**

- **Order List**: A detailed table that lists all orders placed through the website.
  - **Order ID**: Unique identifier for each order.
  - **Customer Name**: The name of the customer who placed the order.
  - **Product(s) Ordered**: List of products included in the order.
  - **Quantity**: The number of items ordered.
  - **Total Price**: The total amount for the order.
  - **Order Status**: Indicates whether the order is pending, completed, or canceled.
  - **Action Buttons**: Options to view or update order details.
    - **View**: Opens a detailed view of the order for review.
    - **Update**: Allows the admin to change the order status (e.g., from Pending to Completed).

### 5. **Inventory Management**

- **Product List**: A table displaying all products available across the different companies.
  - **Product Name**: Name of each product.
  - **Company**: The company associated with the product.
  - **Stock Level**: Current quantity available in stock.
  - **Price**: Selling price of each product.
  - **Action Buttons**: Options to edit or delete products.
    - **Edit**: Redirects to a form for updating product details, including name, stock, and pricing.
    - **Delete**: Removes the product from the inventory with a confirmation prompt.
  - **Add Product Button**: A prominent button that opens a form for the admin to input details for new products to be added to the inventory.

### 6. **Reports Section**

- **Generate Reports**: Functionality that allows the admin to create detailed reports based on various criteria.
  - **Filters**: Admin can select filters such as date range, specific company, or product type to customize the report.
  - **Download Option**: Admin can download generated reports in formats like PDF or CSV for offline analysis or record-keeping.

### 7. **Settings**

- **User Management**: Allows the admin to manage other users with admin access, including adding new users or removing existing ones.
- **Business Information**: Section to update key business details such as contact information, operating hours, and any other relevant data.
- **Permissions**: Configure what different users can access within the admin panel, ensuring that sensitive information is protected.

### 8. **Footer**

- **Links**: Includes quick links to help resources, privacy policy, terms of service, and customer support contact information.
- **Copyright Notice**: Displays the year and the name of the company, reinforcing brand identity.

### User Experience Considerations

- **Intuitive Navigation**: The layout should facilitate easy navigation, ensuring that the admin can find necessary features without confusion.
- **Feedback Mechanisms**: After any significant action (e.g., updating an order or product), the admin should receive a notification confirming that the action has been completed successfully.
- **Accessibility Features**: Ensure the admin page is usable for individuals with disabilities, offering keyboard navigation and compatibility with screen readers.
